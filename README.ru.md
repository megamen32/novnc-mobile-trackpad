# noVNC Mobile Trackpad — инструкция на русском

Мобильная страница для существующего noVNC. Приближение двумя пальцами, тачпад с относительным перемещением, автоматическое следование изображения за курсором при увеличении, отдельные кнопки ЛКМ/ПКМ и клавиатура.

**Установка:** скопируйте файл `mobile.html` в корень установленного noVNC (рядом с папкой `core`), затем откройте `https://ВАШ_ДОМЕН/mobile.html`.

```sh
sudo install -m 644 mobile.html /usr/share/novnc/mobile.html
```

**Требования:** в корне noVNC должен находиться `core/rfb.js`, а WebSocket-соединение с VNC должно работать на пути `/websockify` того же домена. Публичный адрес должен быть защищён HTTPS и авторизацией.

**Управление:** одним пальцем перемещайте курсор, коротким касанием кликайте, долгим удержанием перетаскивайте, щипком двумя пальцами меняйте масштаб 1–8×, двумя пальцами параллельно прокручивайте страницу. При увеличении курсор фиксируется в центре экрана. Кнопка масштаба сверху сбрасывает увеличение.

Код проверен на Ubuntu/noVNC 1:1.0.0-5; в других версиях возможны несовместимости с внутренним API noVNC.

Подробности и лицензии см. в [README.md](README.md).
